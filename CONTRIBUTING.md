# Contributing to Skills Collection

Thank you for your interest in contributing to this skills collection!

## How to Contribute

### Adding a New Skill

1. **Create a skill file** in the `skills/` directory
   - Use a descriptive kebab-case filename (e.g., `my-skill-name.md`)
   - Skills are written in Markdown format

2. **Follow the skill structure**
   - Start with a clear title and description
   - Include usage examples where appropriate
   - Document any prerequisites or dependencies
   - Provide clear, actionable instructions

3. **Test your skill**
   - Verify the skill works as expected with Claude Code
   - Test edge cases and common scenarios

4. **Update the README**
   - Add your skill to the "Available Skills" section
   - Include a brief description

### Skill Guidelines

- **Clarity**: Write clear, concise instructions
- **Completeness**: Include all necessary context and steps
- **Examples**: Provide practical examples when possible
- **Maintenance**: Keep skills up-to-date with current best practices

### Submitting Changes

1. Fork the repository
2. Create a feature branch (`git checkout -b add-new-skill`)
3. Commit your changes (`git commit -m 'Add new skill for X'`)
4. Push to the branch (`git push origin add-new-skill`)
5. Open a Pull Request

### Pull Request Process

- Provide a clear description of what the skill does
- Explain the use case and benefits
- Reference any related issues or discussions
- Ensure all files follow the repository structure

## Code of Conduct

- Be respectful and constructive
- Focus on the skill's utility and clarity
- Help maintain a welcoming environment

## Questions?

Open an issue for discussion or clarification.

Thank you for contributing!
